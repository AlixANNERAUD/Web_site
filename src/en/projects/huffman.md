# Huffman (de)compressor

**C** · 2023

> A Huffman compressor/decompressor written in C with bitstream processing.

## Overview

Implemented a Huffman (de)compressor from scratch in C, covering tree construction, canonical encoding, and bitstream I/O, an exercise in data structures, bit manipulation, and file handling.

## Engineering approach

The project implements a lossless compression algorithm from building a coding tree to processing binary streams. It makes bit-level representation and file I/O constraints visible in C.

## Scope and limitations

Academic or research work, potentially collaborative. It illustrates an engineering method or experiment rather than claiming a commercially deployed product.
