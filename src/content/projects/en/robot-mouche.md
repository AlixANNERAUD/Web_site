# Robot mouche

**C++** · 2023

> A C++ robot combining Wi-Fi remote control, line following and obstacle avoidance.

## Overview

Designed and programmed a versatile robot in C++: it can be driven remotely via WiFi or operate autonomously, following a line and avoiding obstacles using a LiDAR sensor and a camera.

## Engineering approach

The robot combines Wi-Fi remote control with autonomous, sensor-driven behavior. Its software integrates motors, camera and range sensing while keeping the device remotely operable.

## Scope and limitations
