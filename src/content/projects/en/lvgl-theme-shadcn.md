# lvgl_theme_shadcn

**C99 · LVGL · Rust · UI** · 2026 – present

> A shadcn/ui-inspired LVGL 9 theme: widget styling, light/dark palettes and customizable embedded interfaces.

## Overview

A C99 theme for LVGL 9 that brings shadcn/ui-inspired styling to embedded graphical interfaces. It provides light and dark palettes, component roles, and touch-friendly variants for small displays. The repository also offers `no_std` Rust bindings and render examples. [Code and screenshots](https://github.com/AlixANNERAUD/lvgl_theme_shadcn).

## Engineering approach

The theme centralizes visual design for LVGL 9 widgets instead of restyling each component state in every application. The repository contains render screenshots and a reusable C99 library, including Rust integration.

## Scope and limitations

Designed as a reusable library independent of one application. Refer to the upstream repository for current APIs, examples, platform constraints and supported versions.
