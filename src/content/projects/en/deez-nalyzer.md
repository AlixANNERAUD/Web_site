# Deez'Nalyzer

**Django · Vue.js · ML** · 2024

> A Django/Vue application using audio analysis and machine learning to classify music genres.

## Overview

Built a full-stack web application integrating the Deezer API to extract audio features from MP3 excerpts. Trained and compared machine learning models to classify song genres and generate thematic playlists.

## Engineering approach

The architecture connects music API ingestion, audio feature extraction, model training and a Django/Vue interface. The engineering value lies in linking a data pipeline, ML experimentation and a web product.
